# \# RUGD Intelligence — Standardized Assessment Methodology

# \*\*Version 1.1 | Pilot Phase | November 2026\*\*

# 

# \## Purpose

# Provide a consistent, transparent framework for evaluating business opportunities and operational improvements. The methodology supports startup feasibility, expansion feasibility, and operational performance diagnostics. It must be capable of recommending against a proposed action when evidence does not support proceeding.

# 

# \## Core Principles

# \- Stewardship orientation: prioritize long-term enterprise strength (productive capital investment, governance quality, workforce capability, customer value, operational resilience, institutional continuity) over short-term extraction.

# \- Evidence hierarchy: distinguish verified data, user-supplied assumptions, and AI-generated interpretations. Never present the latter as fact.

# \- Deterministic calculations: all financial arithmetic occurs in code or spreadsheets, not language-model generation.

# \- Explicit risk flags and “recommend against” criteria.

# \- Human approval required for final recommendations and any material business decision.

# \- Investor-facing release occurs only after the human review gate and satisfaction of the Investor Readiness Gate.

# 

# \## Evaluation Dimensions

# 1\. Market \& Demand Reality  

# 2\. Competitive Position \& Differentiation  

# 3\. Financial Feasibility \& Capital Requirements  

# 4\. Operational Readiness \& Capacity  

# 5\. Risk Profile (market, execution, financial, regulatory)  

# 6\. Stewardship Indicators (reinvestment capacity, resilience, continuity potential)  

# 7\. Implementation Feasibility (for AI or operational improvements)

# 

# \## Scoring Approach

# \- Each dimension scored 1–5 with written justification.  

# \- Overall feasibility score is a weighted average (weights adjustable by engagement type).  

# \- Automatic flags trigger “recommend against” or “conditional only” outcomes:  

# &#x20; - Insufficient evidence of demand  

# &#x20; - Negative or marginal cash-flow under base and downside cases  

# &#x20; - Founder/operator capacity inadequate for the proposed scope  

# &#x20; - Material unresolved regulatory or liability issues  

# &#x20; - Stewardship indicators show extraction without reinvestment capacity

# 

# \## Investor Readiness Gate

# An assessment may be marked investor-ready only when:

# \- Human review is complete and release is explicitly approved.

# \- No recommend-against flags are active (or conditional flags have accepted mitigations).

# \- Base-case cash flow is non-negative and downside DSCR meets the engagement minimum (default 1.00x; lender-oriented ≥ 1.25x).

# \- Demand evidence is verified or clearly labeled with a verification plan.

# \- Material regulatory or liability issues are resolved or disclosed with mitigations.

# \- Stewardship indicators do not show extraction without reinvestment capacity.

# 

# \## Output Requirements

# Every assessment must include:  

# \- Executive summary with clear go / conditional / do-not-proceed recommendation  

# \- Evidence base and assumption list  

# \- Financial summary (base, downside, break-even)  

# \- Key risks and mitigations  

# \- Stewardship observations  

# \- Recommended next actions (including “stop”)  

# \- Investor-readiness status (internal / conditional / investor-ready)

# 

# \## Pilot Constraint

# Initial use limited to RUGD Intelligence itself, Bunny Hive, and the Small Town Pub pilot. Methodology refinements occur only after documented pilot results.
