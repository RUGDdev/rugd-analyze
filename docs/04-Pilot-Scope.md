# \# RUGD Pilot Scope

# \*\*Version 1.1\*\*

# 

# \## Approved Pilots

# 1\. RUGD Intelligence (self-assessment of the venture itself)  

# 2\. Bunny Hive (as previously defined in project discussions)  

# 3\. Small Town Pub (Inspiration Landing, Sheffield, Alabama)

# 

# \## In-Scope for MVP

# \- Standardized intake  

# \- Deterministic financial modeling  

# \- Methodology-driven scoring and recommendation  

# \- Report generation  

# \- Manual human review and approval step  

# \- Investor Readiness Gate (status flag and one-page summary only)

# 

# \## Out-of-Scope for MVP

# \- Fully autonomous client acquisition or outreach  

# \- Unattended operational changes to live businesses  

# \- Institutional LongArc ratings product  

# \- Multi-user SaaS platform  

# \- Automated investor matching, outreach, or capital movement  

# \- Any process that runs on or accesses the personal Mac

# 

# \## Success Criteria (Pilot)

# \- Complete assessments delivered for the named pilots  

# \- Delivery time and founder effort documented  

# \- Clear statement of whether pricing and process are viable  

# \- List of methodology or architecture changes required before any expansion  

# \- Documented examples of investor-readiness decisions (approved and withheld)
